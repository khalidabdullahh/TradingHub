# 🤝 Contributing to TradingHub / Lumen OS

Thank you for your interest in contributing to **TradingHub** and the **Lumen OS** quantitative architecture!

This repository contains the public specifications, architecture diagrams, and community documentation for Lumen OS, designed and exclusively owned by **Khalid Abdullah**.

---

## 🛠️ Contribution Guidelines

1. **Feature Proposals & Discussions:**
   - To propose charting module extensions, indicator transpilers, or telemetry optimizations, please open a GitHub Issue first.
2. **Pull Requests:**
   - Fork the repository.
   - Create a clean feature branch: `git checkout -b feature/proposal-name`.
   - Submit a Pull Request against `main` detailing the architectural adjustment.
